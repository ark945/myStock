⚡ Rate Limit 優化策略
• 台股：所有追蹤個股合併為「單一 HTTP 請求」（用 | 串接代號），避免被 TWSE 封鎖 IP
• 美股：使用 yf.Tickers() 批次初始化 + fast_info 輕量查詢，避免觸發 Yahoo 429 錯誤
• 基本面：僅在初次加入或每 24 小時更新一次（PE/殖利率/Beta 等低頻變動指標）
• 智慧快取：盤中快取 10 秒有效 / 盤後快取至下次收盤前持續有效
