1-1. 功能截圖：追蹤清單頁面與指標說明

📋 表格欄位說明

  • 股票資訊 — 代號、名稱、市場標籤(TW/US)、健康度評分
  • 建倉與目標 — 建倉價、建倉日、目標價、距目標百分比
  • 最新股價 — 即時價格、今日漲跌額/幅、52週區間圖示
  • 累計損益 — 與建倉價比較之漲跌幅(%)、每張損益金額
  • 估值 (PE/殖利率) — 本益比(PE)、現金股息殖利率
  • 市場 (市值/成交量) — 總市值(兆/億)、當日成交量(張)
  • 體質 (ROE/營收YoY) — 股東權益報酬率、年營收成長率
  • 走勢 (30天) — 近30日收盤價 Sparkline 迷你折線圖
  • 操作 — 排序▲▼、籌碼、股利、編輯✏️、刪除🗑️

🔧 操作按鈕功能

  • ▲ ▼ 排序 — 將個股在清單中上移/下移
  • 籌碼 — 主力買賣超、三大法人（外資/投信/自營商）買賣超與連買連賣天數、融資融券餘額變化（僅台股）
  • 股利 — 查看當年度配息/配股資訊，含除息日、除權日、發放日、每股配息金額
  • ✏️ 編輯 — 修改建倉日、建倉價、目標價
  • 🗑️ 刪除 — 從追蹤清單中移除該個股

🩺 健康度評分 (滿分 5 分)

  • 健康 4~5 體質強健、趨勢佳
  • 調整 3 中規中矩、整理期
  • 警示 0~2 趨勢偏空、風險高
5 項評分依據：
① 均線趨勢：價格 > 50MA > 200MA
② 52週位置：區間百分比 < 85%
③ 合理估值：PE < 25 或 殖利率 > 3%
④ 財務安全：流動比率 > 120%
⑤ 市場風險：Beta < 1.3

🎨 顏色與符號

  • ■ 紅色 上漲 / ■ 綠色 下跌（台股慣例）
  • ↗ 高於建倉價 / ↘ 低於建倉價
  • 🔄 價格變動時閃爍動畫提示
  • ━●━ 52週區間位置指示條

⚡ Rate Limit 優化策略
• 台股：所有追蹤個股合併為「單一 HTTP 請求」（用 | 串接代號），避免被 TWSE 封鎖 IP
• 美股：使用 yf.Tickers() 批次初始化 + fast_info 輕量查詢，避免觸發 Yahoo 429 錯誤
